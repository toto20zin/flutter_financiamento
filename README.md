# flutter_simulador_investimentos

- Simulador de Financiamento

Projeto desenvolvido em Flutter com o objetivo de praticar conceitos iniciais de desenvolvimento mobile, criando uma aplicação capaz de simular financiamentos com cálculo de juros.

 - Funcionalidades
Cálculo automático de parcelas utilizando Tabela Price
Exibição do valor total do financiamento
Interface simples, limpa e intuitiva
Entrada de dados personalizados:
Valor do financiamento
Taxa de juros
Número de parcelas
Taxas adicionais

- Como executar o projeto

Siga os passos abaixo para rodar o projeto localmente:

# Clone o repositório
git clone https://github.com/toto20zin/flutter_financiamento.git

# Acesse a pasta do projeto
cd flutter_financiamento

# Instale as dependências
flutter pub get

# Execute o projeto
flutter run
